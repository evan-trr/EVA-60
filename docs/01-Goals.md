# Goals

This document summarizes the objectives that guide the EVA-60 design.

## Primary goals

- Create a custom mechanical keyboard with a strong Eva-inspired identity
- Keep the project open, documented, and easy to understand
- Favor durability, repairability, and clarity in the design
- Build a future-ready firmware path compatible with open keyboard ecosystems

## Secondary goals

- Explore a compact HHKB-style layout
- Keep the design practical for prototyping and iteration
- Make the project approachable for future contributors

## Current status

The core direction is clear, but some goals will evolve as the hardware and firmware work becomes more concrete.
