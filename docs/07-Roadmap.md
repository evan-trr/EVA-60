# Roadmap

This page tracks the current milestones for EVA-60.

## Current phase

The project is still in design and documentation mode. The next step is to convert the current concept into concrete hardware choices.

## Short-term milestones

- [ ] Choose the microcontroller.
- [ ] Confirm the key components.
- [ ] Lock the electrical constraints.
- [ ] Draft the first schematic.
- [ ] Start the first PCB layout.

## Prototype milestones

- [ ] Validate the PCB revision.
- [ ] Check firmware bring-up.
- [ ] Review mounting and case fit.
- [ ] Build the first prototype.

## Longer-term milestones

- [ ] Refine the case design.
- [ ] Improve the documentation with build notes and photos.
- [ ] Prepare the project for a public release cadence.
