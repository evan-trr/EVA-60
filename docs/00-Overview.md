# Overview

EVA-60 is an open hardware keyboard project inspired by the visual language of Evangelion. The goal is to create a custom HHKB-inspired mechanical keyboard with a strong identity, practical usability, and a well-documented development path.

## Document purpose

This page is the entry point for the EVA-60 documentation set. It explains the scope of the project and how the rest of the documentation is organized.

## Documentation map

- [Goals](01-Goals.md) - design principles and long-term objectives
- [Specifications](02-Specifications.md) - early constraints and assumptions
- [Hardware](03-Hardware.md) - PCB, components, and electrical architecture
- [Firmware](04-Firmware.md) - firmware direction and QMK-related planning
- [Assembly](05-Assembly.md) - build and mounting process
- [Manufacturing](06-Manufacturing.md) - production and prototyping path
- [Roadmap](07-Roadmap.md) - current milestones and next steps

## Current status

The project is in early development. The overall direction is defined, while several implementation details remain open.
