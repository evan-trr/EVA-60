# Overview

This document is the entry point for EVA-60. It explains what the project is, how the documentation is organized, and what readers can expect from each section.

## What EVA-60 is

EVA-60 is an open hardware keyboard project inspired by the visual language of Evangelion. The goal is to create a custom HHKB-inspired mechanical keyboard with a strong identity, practical usability, and a well-documented development path.

## Documentation structure

The documentation is organized as follows:

- Overview: this file, which introduces the project and explains the documentation layout
- Goals: the design principles and long-term objectives
- Hardware: the PCB, components, and electrical architecture
- Firmware: the keyboard firmware strategy and QMK-related planning
- Assembly: the build and mounting process for the keyboard
- Manufacturing: the production and prototyping path

## Current status

The project is still in early development. The overall direction is defined, but several technical decisions are still being refined.
