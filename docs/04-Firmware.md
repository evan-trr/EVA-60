# Firmware

This document covers the firmware direction for EVA-60.

## Goal

The firmware should be practical, open, and compatible with common keyboard workflows. QMK is the main reference point for the current direction.

## Planned topics

- Keymap definition.
- Layer management.
- Macro and custom behavior strategy.
- QMK-related script organization.
- Testing and flashing workflow.

## Status

Firmware planning is still early. The structure and implementation details will be refined as the hardware platform becomes clearer.
