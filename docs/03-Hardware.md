# Hardware

This document is the reference for the keyboard hardware design.

## Scope

The hardware direction currently focuses on a custom PCB and a compact keyboard structure inspired by HHKB-style layouts. The exact component choices are still being evaluated.

## Planned topics

- Microcontroller selection.
- PCB layout strategy.
- Switch and stabilizer choices.
- Power and connectivity considerations.
- Mounting and case integration notes.

## Component inventory

The component list will be documented here as the design becomes more concrete. For now, the emphasis is on defining the architecture rather than finalizing every part.

## Status

Hardware development is in progress. This page will become more detailed as the PCB design progresses.
